A book is only interesting if it beats those. In a rising market almost any book shows a profit, which is exactly how strategies get adopted that have no edge at all.

Every rule here was fixed on data before 2023-12-31, and this replay runs after it, so the result is genuinely out of sample. The live stance uses consensus revisions and implied moves; neither exists historically, so the replay scores a proxy stance built only from features observable at the time.
